## 🎯 Das Finja-Projekt: Ein Überblick

### Was heute schon läuft (Stand 2026):
* 🗣️ **Stimme & Gehör:** Finja kann jetzt hören und sprechen (TTS/STT Integration via Whisper & Co.). **(Neu!) - Disclaimer: Nicht stabil!! noch nicht veröffentlicht!** 
* 🏠 **Haus-Kontrolle:** Sie hat Zugriff auf Sensoren, Licht und Dokumente (Home Assistant & Paperless). **(Neu!)**
* 💌 **Persönlichkeit:** Finja führt menschenähnliche Konversationen mit Emojis, Memory und "eigenem Willen".
* 🌐 **Web-Zugriff:** Autonome Recherche über Tor/DuckDuckGo mit Google-Fallback.

### Die Vision für Morgen (Roadmap 2026):
* 🧠 **Training 6.0:** Das ultimative Ziel bleibt das Training von "Finja 6.0" auf einem perfekt bereinigten, eigenen Datensatz.
* 🎮 **Game-Integration:** Tiefere Verknüpfung von Finja mit Spiele-Events im Stream (Live-Kommentar).
* 📱 **Mobile V2:** Die App weiter ausbauen für noch mehr "Unterwegs"-Features. **Disclaimer: V1 ist nicht veröffentlicht! debug tests!**
